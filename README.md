# コマンドバトル(Command Battle)

3すくみ(PUNCH/UPPER/GUARD)を軸にした、モバイル向けブラウザカードバトルゲーム。

## 起動方法

`index.html` をブラウザで直接開くだけで動作する(ビルド不要)。
`fetch`等を使わないため、ローカルサーバーなしでファイルを開いても動く。

## フォルダ構成

```
command-battle/
├── index.html          # 画面構造(HTML)
├── css/style.css        # スタイル
├── js/script.js         # ゲームロジック本体(憲法二十六条を先頭コメントに含む)
└── assets/
    ├── images/
    │   ├── characters/        # 味方スプライト(必須アセット)
    │   ├── characters_enemy/  # 敵専用スプライト(任意・共通1セット)
    │   ├── backgrounds/       # 背景(任意)
    │   ├── logo/               # ロゴ画像(任意)
    │   ├── cards/               # カード画像(任意)
    │   └── cutscenes/
    │       ├── opening/         # プロローグ画像(任意)
    │       └── story/           # ストーリー画像(任意)
    ├── audio/(bgm, se)          # 未使用・将来のサウンド実装用に予約
    └── fonts/                    # 未使用・将来の独自フォント用に予約
```

各アセットの必須/任意の区別、命名規則、未配置時のフォールバック挙動は [`ASSETS.md`](./ASSETS.md) を参照。

## ドキュメント一覧

このプロジェクトは複数のAI/開発者による共同作業を前提としている。
作業内容に応じて、以下のドキュメントを必要な分だけ読むこと(無関係なドキュメントまで毎回読み込む必要はない)。

| ファイル | 内容 | いつ読むか |
|---|---|---|
| [`AI_GUIDE.md`](./AI_GUIDE.md) | AIが作業する際に必ず守るべき運用ルール | **コードやドキュメントを編集する前に必ず読む** |
| [`CONSTITUTION.md`](./CONSTITUTION.md) | ゲームの設計原則・バトルルール・演出仕様(憲法二十六条) | バトル・演出・UIロジックを変更/実装する時 |
| [`ARCHITECTURE.md`](./ARCHITECTURE.md) | `js/script.js`内の関数マップ・`state`スキーマ(コードのどこに何があるか) | 修正/実装箇所を探す時。全文検索の代わりに使う |
| [`ASSETS.md`](./ASSETS.md) | アセットの命名規則・必須/任意の区別・配置場所 | 画像などのアセットを追加/差し替えする時 |
| [`IMPLEMENTATION.md`](./IMPLEMENTATION.md) | 現在実装済みの機能一覧 | 既存機能の把握・仕様確認をする時 |
| [`TODO.md`](./TODO.md) | 未実装・今後の予定 | 次に着手するタスクを探す時 |
| [`KNOWN_ISSUES.md`](./KNOWN_ISSUES.md) | 実装済み機能の既知の不具合 | 実装済み機能が期待通り動かない時、または不具合を報告する時 |
| [`TESTING.md`](./TESTING.md) | 手動確認チェックリスト(自動テストなし) | コード変更後、動作確認する時 |
| [`CHANGELOG.md`](./CHANGELOG.md) | 変更履歴 | 過去の変更経緯を確認する時、または変更を加えた後の記録時 |

## 作業ルールの要点(詳細は AI_GUIDE.md を参照)

- `js/script.js` 冒頭の憲法二十六条(`CONSTITUTION.md` と同一内容)は省略・簡略化してはならない。
- コードを変更した場合は `IMPLEMENTATION.md` / `TODO.md` / `CHANGELOG.md` を作業の一部として更新すること。
- 未確認の仕様を推測で書き足さないこと(ドキュメント・コードコメントとも)。
